Principais formatações de texto

Negrito / Destaque

Negrito não semantica

Nessa frase temos um termo em negrito usando a tag <b> que não é semnatica, apenas dá forma para o texto

Negrito semantica

Nessa frase temos um termo em negrito, usando a tag <strong> que é semantica, que dá sentido a frase e é semantica

Itálico / Ênfase

Itálico não semântico

Nessa frase temos um termo em itálico, usando a tag <i>, que é uma tag não semantica, apenas dá forma para o texto

Itálico semântico

Nessa frase temos um termo em Ênfase, uando a tag <EM>, que é semântica, que dá sentido a frase.

Tag Mark

Texto Marcado

Podemos criar tambem um texto marcado usando a tag <mark>

Texto Marcado com outra cor

Podemos cirar um texto marcado com outra cor, utilizando a tag mark e aplicando forma com CSS.

Texto grande e texto pequeno

Texto grande não semântica

Nesta frase temos um texto grade utilizando a tag <big> que é uma tag não semântica, tendo apenas forma para deixa o texto grande

Texto pequeno semântico

Nesta frase, temos um texto pequeno, utilizando a tag <small> que é muito utilizada para elaboração de contratos, ou até mesmo uma informação que não tem muita relevancia e normalmente e colocada com texto pequeno.

Texto deletado e texto inserido

Texto que foi deletado

Podemos marcar um texto que foi excluido utilizando a tag <dell> para indicar que ele dever ser lido, mas não considerado

Texto qeu foi inserido

Podemos marcar um texto como inserido utilizando a tag <ins>para dar uma Ênfase e indicar que ele foi adicionado depois que tem um significado e sendo uma tag semantica

Texto que foi sublinhado (Não semântico)

Existe tambem a tag <u> que é utilizada para sublinhar o texto, não semântica, pois não tem significado e apenas forma

Texto alto e texto baixo

Texto sup (em cima)

Abaixo um texto com a tag <sup>, que normalmente é utilizada para inserir formulas de matematica x20 +3

Texto sub (em baixo)

Abaixo um texto com a tag <sub>, que normalmente é utilizado para inserir formulas de quimica H20
